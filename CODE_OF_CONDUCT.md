# How we talk to each other here

shill is a small project and we want it to stay a nice place to send a patch.

- Be kind about code and direct about problems. "This breaks on Windows paths" is
  great. Anything aimed at a person instead of the code is not.
- No harassment, slurs, sexual content or pile-ons, in issues, PRs, discussions or DMs
  about the project.
- Maintainers can edit, hide or lock anything that crosses the line, and block repeat
  offenders.

If someone makes you uncomfortable, message a maintainer or open a private advisory at
https://github.com/OWNER/shill/security/advisories/new. We keep reports private.
